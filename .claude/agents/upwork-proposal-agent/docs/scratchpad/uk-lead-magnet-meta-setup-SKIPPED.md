## Learning-phase arithmetic (the substantive finding)
GBP 300 over 14 days = ~GBP 21/day.
Post wants "a small number of different hooks/creatives/audiences" tested.
3 ad sets => ~GBP 7/day each = ~GBP 49/week each.
Meta needs 50 optimisation events per ad set per week to exit learning phase.
  GBP 49 / 50 = GBP 0.98 required cost per email signup.
Realistic UK cold cost per lead-magnet signup: landing page GBP 3-8; Instant Forms GBP 1.50-4.
  => Landing page: off by 3-8x. Instant Forms best case: still ~1.5x short.
Total signups across whole test at GBP 4 blended: ~75. Split 3 ways = ~25/variant.
Calling a hook winner wants 50-100 conversions per variant => off by 2-4x.
Collapsing to ONE ad set (defeats the stated purpose): ~37 signups/week, still under the 50 bar.

CONCLUSION: GBP 300 buys roughly ONE readable signal (does the offer convert at all, and in what
CPL band). It does not buy the hook/audience/creative test the post is explicitly asking for.
The client's stated objective and stated budget are in direct conflict. That is an honest and
useful diagnosis independent of whether we bid.
