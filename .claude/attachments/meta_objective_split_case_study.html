THE SETUP

One Variable, Held Clean

The account ran two campaigns side by side for the full month. Same account, same audience pool, same launch day, same budget to within a hundred dollars. The only difference between them was the conversion event each one was told to optimize toward. One was set to Engagement. One was set to Leads.

What this case study does not claim

An Engagement objective would not record lead events in the first place, and this account had no call tracking, so we cannot show that the Engagement campaign drove zero phone calls. The defensible finding is that it produced not one recorded enquiry, and that no mechanism existed to prove otherwise. The measurement gap and the performance gap were the same gap.

Both campaigns stopped spending at the end of this window, so the figures describe one month and are not presented as a trend.
